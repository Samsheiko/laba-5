# Задание 2







###



### Текст задачи







#### Определить количество ненулевых элементов списка.







### Алгоритм решения







#### Алгоритм работы программы начинается с вызова предиката start. Далее основной предикат разделяет список на голову (первый элемент) и хвост (остаток). Если список пуст, возвращается ноль. Для непустого списка программа рекурсивно вычисляет количество ненулевых элементов в хвосте, после чего проверяет голову: если она не равна нулю, к общему счетчику прибавляется единица, иначе значение остается прежним. Итоговый результат выводится на экран.

### Алгоритм решения







#### Решение задачи начинается с генерации всех возможных распределений 4 цветов среди 4 котят и распределения этих котят среди 4 мальчиков, затем для каждого варианта определяются цвета питомцев у каждого мальчика. Далее программа поочередно проверяет все 10 утверждений задачи, присваивая каждому флаг 1 (если истинно) или 0 (если ложно), суммирует значения всех полученных флагов, проверяет равенство этой суммы числу 9 (что означает, что ровно одно утверждение ложно), после чего отсекает неверные комбинации с помощью автоматического возврата и выводит на экран итоговое правильное распределение мальчиков, котят и их цветов.
